# G-Commons Modules

Reusable, game-agnostic Godot modules belong here.

- Give each module a clear folder and responsibility.
- Include a module README describing API, dependencies, lifecycle, and usage.
- Keep game-specific rules and content out of this directory.
- Do not add modules solely because they might be useful someday.
- Prefer modules that solve a demonstrated need and can be tested independently.

The first production module has not been selected. Game requirements should guide the first abstraction rather than speculative infrastructure.
